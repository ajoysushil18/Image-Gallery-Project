# Nature's Canvas — Image Gallery Project

A clean, minimalist, and responsive single-image gallery website built with pure HTML5 and modern CSS3.

## 📁 Project Structure

```text
Image-Gallery-Project/
│
├── index.html                  # Main HTML file
├── public/
│   └── assets/
│       └── image1.jpg          # Single featured image
└── src/
    └── components/
        └── gallery.css         # Component styling
```

## 🌟 Features

- **Single Featured Card Layout**: Perfectly balanced, centered showcase card for maximum visual impact.
- **Natural Organic Aesthetic**: Warm earthy tones, soft ambient gradients, and crisp modern typography.
- **Pure HTML5 & CSS3**: Zero heavy external dependencies, extremely fast loading.
- **Fully Responsive**: Adapts seamlessly to desktops, tablets, and mobile phones.
- **Smooth Micro-interactions**: Elegant hover lift and subtle image zoom transitions.

## 🚀 How to Run Locally

Simply double-click `index.html` to open it in your browser (Chrome, Edge, Firefox), or use VS Code's **Live Server** extension.
